# 测试 1：交互分割检测与验收流程

本流程用于提交前自检，也可以直接作为课堂现场演示脚本。建议在老师规定的最终电脑上完整执行一次。

测试 2“路径文字”和测试 3“平/柱面贴图”的完整检测流程另见 `TEST2_3_CHECKLIST.md`。

## 一、运行环境检查

1. 暂时断开网络，或关闭 Wi-Fi。
2. 打开终端并进入项目目录。
3. 执行：

   ```bash
   python -m pip install -r requirements-dev.txt
   python scripts/verify_project.py
   python -m unittest discover -s tests -v
   python main.py
   ```

4. 检查软件正常启动，底部状态栏显示“CPU 离线 · OpenCL 关闭”。
5. 检查程序在断网状态下仍可读取、分割和保存图像。

通过标准：项目检查无错误；程序启动过程中不请求网址、账号、模型或远程服务器。

Windows 使用 `setup_windows.bat` / `run_windows.bat`；macOS 使用
`setup_macos.command` / `run_macos.command`。两台验收机都应分别完成本节命令和至少一次保存。

## 二、基本功能逐项检测

### 1. 读取与显示

1. 点击“打开规定测试图”。
2. 依次尝试读取 `LENA.jpg`、`baymax.jpeg`、`cat.jpg`。
3. 检查原图不变色、不拉伸，底部显示正确文件名与图像尺寸。
4. 每次读取后检查操作时间从 `0.0 s` 开始，交互次数为 `0`。

通过标准：三张图均可读取，特别是 `LENA.jpg` 也能正常打开。

### 2. 第一次矩形初始化

1. 读取 `cat.jpg`。
2. 在未画矩形前选择画笔并尝试操作。
3. 检查程序提示第一次必须使用矩形，且交互次数仍为 0。
4. 选择矩形，紧贴猫的耳朵、头部和身体拖出矩形框。
5. 松开鼠标。

通过标准：右侧自动出现分割轮廓；交互次数变为 1；状态栏显示本次算法毫秒数。

### 3. 九种工具

在已完成矩形初始化的同一张图上逐一选择：

- 直线
- 矩形
- 正方形
- 圆
- 椭圆
- 五边形
- 六边形
- 任意多边形
- 涂抹

每种工具至少执行一次。任意多边形逐点单击，再按 Enter 完成。

通过标准：每完成一个图形，结果自动更新且交互次数只增加 1；不存在坐标偏移。

### 4. 四种标记

1. 用“确定背景”标记明显背景。
2. 用“确定前景”标记目标内部。
3. 分别测试“可能背景”和“可能前景”。
4. 观察左侧标记颜色和右侧轮廓变化。

通过标准：四类标记颜色不同，GrabCut 可以继续迭代，确定前景/背景不会在下一轮被自动覆盖。

### 5. 撤销、重置和计时

1. 记录当前交互次数。
2. 点击“撤销标记”，检查回到上一分割状态，但历史交互次数不减少。
3. 点击“重新开始”，检查时间和次数都归零，结果回到原图。
4. 等待 3 秒，检查秒表持续增长。

通过标准：状态恢复逻辑正确，计时口径与交互计数口径明确。

## 三、三张规定图片的正式实验

正式实验前为每张图点击一次“重新开始”，不要沿用调试过程的次数。

### LENA.jpg

1. 初始矩形框住人物、帽子和肩部。
2. 用确定背景标记左侧柱子和右侧镜面。
3. 用确定前景标记脸部、帽檐和头发内部。
4. 查看二值 mask，修补明显孔洞。
5. 保存全部结果。

检查重点：帽檐不应被截断，镜面人物不应进入前景。

### baymax.jpeg

1. 将中央大白作为唯一前景，矩形紧贴大白主体。
2. 把左侧小男孩、右下方物品和窗外区域标为确定背景。
3. 在大白腹部、手臂和腿部标记确定前景。
4. 切换轮廓与 mask 检查明亮窗户是否误分。
5. 保存全部结果。

检查重点：白色大白与明亮窗户容易混淆，应优先修正这一区域。

### cat.jpg

1. 矩形包含猫的双耳、头部和右下身体。
2. 将左侧及下方绿色模糊区域标为确定背景。
3. 在猫脸、耳朵和身体内部涂抹确定前景。
4. 放大检查耳尖、脸部轮廓和身体右侧。
5. 必要时使用细画笔修正；保存全部结果。

检查重点：猫毛边界尽量连续；胡须极细，不要求每根都完全保留，但不能大面积带入背景。

## 四、保存文件检测

对每一张图片检查结果目录中至少存在：

1. `*_ui.png`：完整窗口截图，底部时间与交互次数清晰可见。
2. `*_mask.png`：与原图宽高一致，单通道，只含 0 和 255。
3. `*_foreground.png`：与原图宽高一致，三通道，背景为黑色。
4. `*_overlay.png`：原图上有清楚的绿色分割轮廓。
5. `*_experiment.json`：记录时间、次数、尺寸，且 `gpu_used` 为 `false`、`opencl_enabled` 为 `false`。

建议用以下 Python 检查 mask；需要已安装 OpenCV：

```python
import cv2
import numpy as np

mask = cv2.imread("results/cat/cat_mask.png", cv2.IMREAD_GRAYSCALE)
print(mask.shape, np.unique(mask))
assert set(np.unique(mask)).issubset({0, 255})
```

## 五、现场演示顺序

1. 展示断网和 CPU 离线状态。
2. 打开 `cat.jpg`，用矩形完成第一次分割。
3. 使用确定前景、确定背景和任意多边形各修正一次。
4. 切换轮廓、RGB 前景和 mask 三种视图。
5. 指出秒表和交互次数，并点击保存。
6. 打开保存目录，展示五个输出文件。
7. 最后展示另外两张图片已经保存的正式实验结果。

整段现场操作建议控制在 3～5 分钟。优先展示分割质量、计时计数和保存结果，不必逐行讲代码。
