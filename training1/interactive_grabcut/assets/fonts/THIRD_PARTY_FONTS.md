# Bundled fonts

All bundled fonts are used locally by the desktop application and are redistributed under the SIL Open Font License 1.1. The license text is in `OFL-1.1.txt`. To keep the portable application practical, each file is a subset containing every character used by the interface, experiment documents, built-in examples and ASCII. The original family names and outlines are preserved.

| File | Family / source |
|---|---|
| `NotoSansCJKsc-Regular.otf` | Noto Sans CJK SC, notofonts/noto-cjk |
| `NotoSerifSC-VF.ttf` | Noto Serif SC, google/fonts |
| `MaShanZheng-Regular.ttf` | Ma Shan Zheng, google/fonts |
| `ZCOOLXiaoWei-Regular.ttf` | ZCOOL XiaoWei, google/fonts |
| `LongCang-Regular.ttf` | Long Cang, google/fonts |

The first family is the cross-platform interface and fallback font. All five are exposed in Test 2 as real selectable Chinese font families; outline, neon, rainbow, weight and slant are separate effects.
